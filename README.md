# Rock Paper Scissors Game

*A simple command-line Rock Paper Scissors game built with Python. Play against the computer and see who wins based on the classic game rules.*

## Features

* User vs Computer gameplay
* Random computer move generation
* Win, lose, and tie detection
* Simple and beginner-friendly Python code
* Command-line interface

## Technologies Used

* Python 3
* Random Module

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/haidar18/rock-paper-scissors-game.git
```

2. Navigate to the project directory:

```bash
cd rock-paper-scissors-game
```

3. Run the game:

```bash
python rps.py
```

## Game Rules

* Rock beats Scissor
* Scissor beats Paper
* Paper beats Rock
* If both players choose the same move, the match is a tie

## Sample Output

```text
Enter your move = Rock, Paper, Scissor: Rock

user choice = Rock, computer choice = Scissor

Rock smashes Scissor = you win
```
